# FUTURE_DS_01 – Business Sales Performance Analysis

## Project Overview
This project analyzes business sales data to understand revenue, profit, product performance, regional sales, sales channels, and monthly trends.

Completed as part of the Future Interns Data Science & Analytics Internship – Task 1.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Microsoft Excel

## Project Structure
- `data/` – Sales dataset
- `notebooks/` – Python sales analysis
- `reports/` – Power BI dashboard, business insights, and visualizations

## Key Business Insights
- Total Revenue: 11.14M
- Total Profit: 2.94M
- Average Order Value: 9.29K
- Total Orders: 1,200
- Total Quantity Sold: 1,200
- South region recorded the highest revenue.
- Furniture was the top-performing product category.
- Online sales generated the highest revenue.
- June recorded the highest monthly revenue.

## Dashboard
The interactive Power BI dashboard is available in the `reports/` folder.

## Note
This project uses a sample dataset for educational and analytical purposes. The results do not represent actual company financial performance.
